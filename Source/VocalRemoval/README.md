# AI vocal removal

This sideloaded edition runs UVR MDX-Net Inst HQ 4 locally through Core ML. The player header shows the toggle when there is room for its 44-point touch target. In compact layouts, open playback options to reach it.

The model uses about eight seconds of buffering. Original audio plays if separation falls behind. The model and DSP were adapted from the HQ 4 release branch of anton86511/EeveeSpotifyReincarnated and keep its GPL-3.0 licensing.
